# Support

Use the right channel so questions are easier to find and answer:

- **Bug:** open a bug report with reproduction steps.
- **Feature request:** open a feature request describing the video or workflow.
- **Question or idea:** use GitHub Discussions.
- **Security issue:** use private vulnerability reporting from [SECURITY.md](SECURITY.md).

PiP Crop is community-supported. Include your browser and version, the install method (`.xpi` or AutoConfig), your Windows version and display scale, and the PiP Crop version, but never publish personal browsing data or private videos.
